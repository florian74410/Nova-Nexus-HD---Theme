# Arborescence cible

- `Old/` : références historiques inertes
- `App/` : fenêtre Paramètres, configuration, catalogue des versions et découverte de plugins
- `Updates/` : index des versions et futurs artefacts
- `Assets/` : ressources visuelles de la nouvelle génération
- `Docs/` : spécifications et documentation
- `Plugins/` : un répertoire indépendant par plugin, paramètres auto-générés

**Priorité suivante :** premier plugin, avec manifeste validé, paramètres et tests dédiés.

# Reconstruction propre — Cyber-Neon Interactif THEME 1.0

Priorités (Linux Mint XFCE / X11 en premier):

1. **P0 — Shell minimal**: démarrage/arrêt, menu Paramètres, thème cyber-neon bleu et bouton de secours bureau natif.
2. **P1 — Mise à jour**: menu accessible dès P0, découverte contrôlée de `Update/index.json`, sélection version stable/latest/historique, SHA-256, téléchargement sûr, restauration/rollback, tests hors-ligne.
3. **P2 — Plugin Manager**: manifeste, API stable, activation/désactivation, erreur isolée par plugin, page Paramètres > Plugins > [plugin], versions par plugin.
4. **P3 — Plugins élément par élément**: CPU, RAM, Réseau, Stockage, GPU, Ventilateurs, Puissance. Chaque plugin a sa page de réglages, tests/mesures et Holo sur clic explicite de son icône.
5. **P4 — Modules visuels**: HUD performance, barre de navigation, latérales, Nova Explorer, Terminal, notifications et décorations XFCE, activables séparément.
6. **P5 — Livraison**: pack Debian Linux validé sur une session isolée X11 et machine Mint, tests de restauration du bureau et installation/mise à jour.

Aucun ancien code de `Old/` n'est chargé automatiquement. Aucun installateur publié tant que le lot correspondant n'est pas validé.

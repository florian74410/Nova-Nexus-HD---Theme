# Cyber-Neon Interactif — v0.1

Base neuve Linux Mint XFCE / Ubuntu X11. Exécution : installer `App/requirements.txt`, puis lancer depuis la racine `python -m App`. La fenêtre Paramètres est autonome ; elle ne masque ni ne remplace les panneaux XFCE. Configuration dans `~/.config/nova-nexus-hd/settings.json` (ou `$XDG_CONFIG_HOME`).

Sections : Générale, Thème Couleurs, Plugins + une section par plugin découvert, Mise à jour, À Propos. L'option 'démarrer minimisé' n'est pour l'instant qu'une préférence, car le futur lanceur n'existe pas encore. Idem pour le système d'installation de mises à jour : lecture d'un catalogue local seulement.
